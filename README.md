# Simple Calculator using Python

A command-line Simple Calculator built using Python. This project performs basic arithmetic operations and provides an interactive menu-driven interface for users.

The application allows users to enter two numbers, choose an operation, and instantly receive the calculated result.

This project is designed for beginners who want to practice Python fundamentals and build a simple interactive application.

## 📌 Project Overview

This project simulates a basic calculator that performs everyday mathematical calculations.

Users can repeatedly perform operations until they choose to exit the application.

The program also includes input validation and error handling to ensure a smooth user experience.

## 🚀 Features

* Addition
* Subtraction
* Multiplication
* Division
* Interactive menu-driven interface
* Input validation
* Error handling for division by zero
* Beginner-friendly implementation
