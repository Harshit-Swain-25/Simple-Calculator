==============================
   Simple Calculator
==============================

Description:
A basic calculator program in Python that can
perform addition, subtraction, multiplication,
and division.

Features:
- Menu-based options
- Handles invalid inputs
- Prevents division by zero
- Runs until user exits

How to Run:
1. Save the file as 01_main.py
2. Open VS Code terminal.
3. Run the program with:
   python3 01_main.py
